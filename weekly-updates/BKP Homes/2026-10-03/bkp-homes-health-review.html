09 · Method

Same seven days in both sources

  • Eighth weekly run. Identity, F-numbers, and history before 26 Sep come from the ledger. Account age (119 days) is the tenant created_at of 2026-06-06, not a range scan. Stored ids returned data, so the name lookup was skipped. No new account placed a call.
  • Window. 2026-09-26 06:30:00 UTC inclusive through 2026-10-03 06:30:00 UTC exclusive. PostHog and Loki both cover that span. Loki retention is 31 days, so this window sits inside it. There is no "logs are shorter than events" caveat this week.
  • Days in the charts run 06:30 to 06:30 so they match the server buckets. Fri 2 includes Saturday morning through 06:30. A calendar date in PostHog is not the same cut.
  • Volume. Loki call-session lines are the call count. Last week 227 info lines sat within 5 percent of 217 model call ids, and analysis dispatch matched 217 for 217. This week dispatch is 206 and model call ids are 133, so PostHog is the scored subset. Connect rate, talk time, and resolution exist only on the 15 call_completed rows after 2 Oct 14:12.
  • 1 Oct is global. $ai_generation has 0 rows for every tenant on that calendar day. This account still had 33 server sessions in the 06:30 day that covers it. Absence there is the pipe, not a closed store.
  • Credits. The 30-day credit_settled baseline is labeled as a baseline, not as this customer's usage. This tenant is 0 on every day of it. Other tenants settled thousands a day until 13 Sep, then the event went quiet with the rest of the pipe, then 16 settlements landed on 2-3 Oct for other tenants only.
  • Grades are model grades. Sentiment and resolution are the model scoring its own transcript. Compare calls inside the account. Do not quote them as a confirmed customer outcome.
  • Prometheus. count by (__name__) ({tenant=~".+"}) on grafanacloud-prom returned no series. No metric carries a tenant label. Checked once.
  • Catalog. The governed metric catalog has no saved definitions. Every figure in this report is a one-off query, not a certified metric.
  • Not in the schema. call_completed has no error_code property this week. Outcomes use status, outcome, ended_by, and escalation_transfer_status. Two phone filters on the call list returned 200. The numbers are omitted on purpose.
  • Still closed without a new card: F6, F8, F10, F12. Reopen F12 only if /proxy/calls returns 500 again. Reopen F15 only if a prompt write returns 400 again.
