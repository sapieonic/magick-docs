09 · Method

What these numbers can and cannot say

  • Ninth weekly run. The ledger already had this tenant. Identity was not re-resolved. No new account id appeared on calls.
  • Both sources cover the same seven days: 2026-10-03 06:30:00 UTC through 2026-10-10 06:30:00 UTC. PostHog events and Loki logs. Days in the charts are 06:30-to-06:30 buckets so a midnight cut does not borrow the previous morning.
  • One longer read, labeled as a baseline and not as this customer’s week: credit_settled from 10 Sep 06:30 through 10 Oct 06:30, this tenant against all tenants.
  • The prior-week column is 26 Sep 06:30 through 3 Oct 06:30. Server session count for that week is from the ledger (215). Product counts for that week were re-queried.
  • Prometheus count by (__name__) ({tenant=~".+"}) on grafanacloud-prom returned no series. No metric carries a tenant label. Checked once.
  • The governed metric catalog for this project is empty. Every figure in this report is a one-off query, not a saved definition.
  • Resolution and sentiment are model grades of the transcript, useful for comparing calls here, not a confirmed business outcome. Gemini cost is unpriced. Do not read it as zero.
  • A zero completion count after 9 Oct 10:00 is missing instrumentation, confirmed because every tenant went to zero while model generations and server logs continued. It is not a silent desk.
  • Loki raw lines were not used. Counts are aggregations on structured metadata. The settlement warning text did not group, so it is not quoted as freshly read.
  • Account age uses groups.created_at 2026-06-06 13:03 UTC, which is 126 days at this cutoff.
