09 · Method

What these numbers can and cannot say

  • Twelfth weekly run. The ledger already had this tenant, so identity was not re-resolved. Call-session accountId is only Inbound cc0bd2e4, 204 of 204 lines. No new account id.
  • Both sources cover the same seven days: 2026-10-24 06:30:00 UTC through 2026-10-31 06:30:00 UTC. PostHog events and Loki logs. Chart days are 06:30-to-06:30 buckets from instant [1d] queries. A midnight range was not used.
  • One longer read, labeled as a baseline and not as this customer’s week: credit_settled from 2026-10-01 06:30 through 2026-10-31 06:30, this tenant against all tenants. Rows exist only on 2–9 Oct.
  • A seven-day all-tenant check on Gemini Live errors: 9 lines, 4 tenants. Used only to see whether the Thursday close was unique. It was not. Other tenants are not named.
  • The prior-week column is the 17–24 Oct ledger. It was not re-queried. Product figures in this report are one-off queries. The governed metric catalog is empty (count 0), so none of these numbers is a saved definition.
  • Prometheus count by (__name__) ({tenant=~".+"}) on grafanacloud-prom returned no series at 2026-10-31 06:30 UTC. No metric carries a tenant label. Checked once.
  • Resolution and sentiment, when they exist, are model grades of the transcript. They were not emitted this week. Gemini cost is unpriced when the generation event exists. This week the event is absent, so cost is unknown, not zero.
  • A zero completion count is missing instrumentation. The events table returned two rows for the whole project, neither of them on this tenant, while this tenant’s server logs continued. It is not a silent desk.
  • Loki raw lines were not used. Counts are aggregations on structured metadata. Settlement warnings, call-session warnings, and webhook-dispatch lines returned an empty label set, so their body text is not quoted as freshly read. The Gemini error did group on code and reason.
  • Account age uses groups.created_at 2026-06-06 13:03 UTC, which is 147 days at this cutoff. That read is the stored property, not a new range scan.
  • Calls can be connected and still fail a later grade, and a session line is not a connect flag. Connect rate is not stated this week because call_completed was not emitted.
