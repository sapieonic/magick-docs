  • Sources. PostHog project 454290, filter $group_0 = ee122920-8af6-4c0d-af1a-3bf4d93c1414.   • Prometheus. Instant count by (__name__) ({tenant=~".+"}) on grafanacloud-prom returned empty. No metric carries a tenant label. Checked once.
  • Governed catalog consulted: no match for a named tenant health metric; all figures are noncanonical event/log aggregations.
  • Resolution and sentiment are model-scored from call_analyzed, not customer-confirmed outcomes.
  • Connect rate uses properties.connected; status success uses status. They disagree here because voicemail is connected and not status=completed.
  • Gemini Live cost is unpriced in PostHog, not zero. gpt-4o analysis is $21.15.
  • call_completed does not stamp $group_1. Per-account voice volume is Loki HTTP (Meesho BOT 11,498, IDFC BOT 2,172), not PostHog calls.
  • matched_intent on call_completed is always null. Do not read 0 matched intents as a prompt miss.
  • Denominators under 10 are labelled: AI_PIPELINE_ERROR on 22 Aug and 28 Aug n=1 each, CALL_NOT_CONNECTED on 28 Aug n=13, ivr-engine error n=2, last-48h 429 n=0, upload fail n=1, MoneyView HTTP n=6, IVR HTTP n=13.
