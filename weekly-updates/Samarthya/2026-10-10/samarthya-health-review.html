09 · Method

What these numbers can and cannot tell you.

  • Windows. PostHog and Loki both cover the same seven days. The PostHog bound is now() minus 7 days and the queries ran from about 04:36 to 04:45 UTC on 10 Oct, so the end moves a few minutes with each query. First event in the window: 2026-10-03 04:39:45 UTC. Last event seen: 2026-10-10 04:38:23 UTC. Last call_completed: 2026-10-09 09:36:55 UTC. Last $ai_generation at snapshot: 2026-10-10 04:36:21 UTC. The prior report’s last console event was 2026-10-03 04:33 and its scored test call completed at 04:30, so this window does not recount that call. Loki retention covers this range. The 30-day credit_settled series is a baseline, not this week’s usage.
  • Sources. PostHog project 454290, timezone UTC, $group_0 = ee122920-8af6-4c0d-af1a-3bf4d93c1414. Short token samarthya. Loki datasource grafanacloud-logs. Services MagickVoice-Platform-Dedicated and MagickVoice-Orchestrator-Dedicated, filtered on tenantId. deployment_environment production, dedicated, or prod. Identity was already on the ledger, so the name scan was skipped. The stored id returned events. The account set did not grow.
  • Prometheus. Instant count by (__name__) of series with tenant=~".+" on grafanacloud-prom returned empty. No metric carries a tenant label. Checked once, 2026-10-10.
  • No blended score. Voice, platform, automations, and console are separate on purpose. An average would hide a working call path under a tape that stopped on Friday.
  • Scored voice is call_completed. Connected is properties.connected, which is not the same as status=completed: 17 failed calls were still connected. Off-tape volume is uniq(call_id) on $ai_generation where the span is post_call_analysis, in hours where call_completed is zero. Those hours have no connect rate.
  • Prior week in the comparison table is the 3 Oct report ledger (3,143 graded, 1 call_completed, 2 console people, 9 sessions, $38.26). It was not re-queried. This run stays on seven days except for account created_at and the 30-day credit baseline.
  • Rates are one-off. No approved catalog metric was reused. Every rate in this report is computed from the queries named on the evidence lines.
  • Model scores are the model grading itself. Resolution, sentiment, and the outcome labels are not a customer-confirmed payment.
  • Zero is not a decline when the event is missing, and zero is not a fix when the button was not pressed. Automations at 0 here, with 929 triggers on other tenants, means unused. Invite 500s at 0 means nobody sent an invite. credit_settled at 0 after 09:36, while grading continues, means the emitter stopped. It does not mean the balance leaked. The 30-day baseline shows the event settling for this tenant every day of the scored window.
  • Loki raw lines were not used. Aggregations on metadata were. A range query for settlement-dispatcher by hour returned no series, which this report treats as a query failure, not as proof the dispatcher stopped.
